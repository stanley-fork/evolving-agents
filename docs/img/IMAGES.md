# Images for the hub (README, `packages/director/`, the website)

Four plates are generated in the house style of lora-kernel's plates (sepia ink and transparent watercolour on
parchment `#F3EBDD`; slate blue `#5B7186`, sage green `#8A9A6B`, rust orange `#B5603A`, ochre `#C9A54A`). One
chart is drawn from committed numbers with matplotlib — never by an image model, which would invent them.

The motifs repeat the existing plates, so a reader recognises each project: **lora-kernel** is a library (a
card-catalogue cabinet, a small brass radar lighting three drawers); **agentvcs** is a machine and its ledger
(a paper ledger whose lines end in wax seals); **gene-evidence** is a naturalist's evidence table (a report whose
lines are threaded to cards). **The director** is new: a chart table with a map of linked index cards and a route
traced on it in red pencil, from which two dispatch tubes leave — one to a window and a distant building (the
frontier), one to a small machine on a nearby bench (the local lane).

**Built vs planned is drawn, not implied:** solid sage-green cord = built; dashed ochre chalk line = planned.
Built today: director → the frontier, director → the local lane, director → the ledger (every memory edit is an
agentvcs patch), library ↔ ledger (agentvcs versions lora-kernel's harness, LK0). Planned: the director's local
lane through lora-kernel's specialists, and gene-evidence to the others.

Every generated plate: no legible text, no letters or numbers, no logos, no people or hands, no robots, no glow,
no gradients, no 3D render, no photographic look.
