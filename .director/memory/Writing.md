# Writing
How docs and comments are written and kept in sync with runs.

## #plain_outcome_first
**When:** writing a doc or a code comment.
**Do:** Use plain words, put the outcome first, keep it short.
**Because:** The lab's writing rule.
**Links:** [[Writing#numbers_carry_brief_link]]

## #numbers_carry_brief_link
**When:** putting a number (a score or result) in a doc.
**Do:** Attach the link to the brief it came from.
**Because:** Numbers carry their brief link; the public site checks its numbers against the briefs.
**Links:** [[Measurements#record_result_in_brief]] · [[Writing#update_citing_docs]]

## #update_citing_docs
**When:** something has run and its result is recorded.
**Do:** In the same change, update every doc that cites it: the brief, `packages/director/README.md`, `ROADMAP.md`, `docs/EVOLUTION.md` and the RUNBOOK.
**Because:** The public site (`evolvingagentslabs.github.io`) checks its numbers nightly against the briefs.
**Links:** [[Measurements#record_result_in_brief]] · [[Writing#numbers_carry_brief_link]]
